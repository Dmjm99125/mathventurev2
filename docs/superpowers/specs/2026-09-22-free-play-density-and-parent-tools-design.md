# Free Play Density and Parent Tools Design

## Goal

Make the Free Play landing page feel lighter for kindergarten learners without redesigning it.

## Approved direction

- Keep the existing Organic/student visual language, topic cards, copy, and offline functionality.
- Reduce only the Free Play intro card's vertical padding and icon footprint so the intro section is thinner.
- Place the existing Offline library panel inside a collapsed native disclosure labeled for parents. It remains available, accessible, and functionally unchanged when opened.

## Success criteria

- The intro still contains “Free Play,” the existing description, and “Explore every topic.”
- The offline library is not expanded by default.
- Opening the parent disclosure reveals the existing download, progress, ready, update, and error states.
- No changes are made to topic navigation or offline download behavior.
