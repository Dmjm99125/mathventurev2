# Red Matching Object Revision

## Goal

Replace the butterfly object in the color matching game with a ladybug while keeping it classified as red.

## Design

Update the red object list in `ColorMatchingGame.tsx` from the butterfly emoji (`🦋`) to the ladybug emoji (`🐞`). No scoring, matching, layout, or other color groups change.

## Verification

Run the project type-check/build validation and confirm the red object list contains the ladybug and no butterfly.
